# Bookmark Board

## Tech Stack
- Java 11
- MySQL 8.0
- Spring Boot 2.7.18
- Spring Security
- MyBatis
- JSP

## Need to set environment
- DB_URL: 데이터베이스의 URL (MySQL 지원)  
- DB_USER: 데이터베이스에 로그인할 떄 사용할 유저명  
- DB_PASSWORD: 데이터베이스에 로그인할 떄 사용할 유저의 비밀번호  
- UPLOAD_FILE_PATH: 업로드된 파일들이 저장될 위치
